# Petalune privacy and support

Public GitHub Pages website for Petalune by Thomas Williams. This repository contains only the website, not game source or assets.

## Pages
- Home: https://overlapdigital.github.io/petalune-support/
- Privacy policy: https://overlapdigital.github.io/petalune-support/privacy/
- Support: https://overlapdigital.github.io/petalune-support/support/

Publish from the main branch, root directory. No build, dependencies or tracking scripts are required.

## Keeping the policy accurate
Review the wording before each App Store submission and whenever services change. The current policy discloses the Google Fonts request in the game. Remove that section only after fonts are bundled locally and the external request is removed from the shipped app. Real-money in-app purchases are currently disabled in the game; purchase language is conditional and must be reviewed when enabling them.

Support correspondence must actually follow the retention and handling practices stated in the policy. Reassess international processing arrangements if service providers change. Review child privacy requirements against the intended age audience and App Store category.

In App Store Connect, enter the privacy and support URLs above. Also add an easily accessible privacy policy link inside the app. Complete App Privacy answers against the actual release build and third-party service practices; do not assume “Data Not Collected” while external requests remain.
